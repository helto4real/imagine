# Archived generation profiles

These historical presets are outside the active, top-level YAML catalog.
`qwen.yaml` and `quick-draft.yaml` provide the standard and Turbo recipes for
both text-only and reference-image generation. Character sheets and upscale
keep their separate operation profiles.

The frozen v2 wrapper is preserved here. Native frozen executables, manifests
and evidence under `experiments/qwen-image21-sage/` are unchanged.
