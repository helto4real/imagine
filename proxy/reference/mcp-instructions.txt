Generate or upscale images using approved workflows. First call describe_workflow for the chosen workflow. If its schema exposes prompt, apply any prompt_guidance to parameters.prompt. Otherwise use the stored workflow prompt. For image_upscale, register exactly one image and pass optional max_side and seed. For workflows with random seed defaults, omit seed for a fresh seed per image or provide an integer for a fixed seed. Results contain the resolved seed. The nsfw flag is an opt-in LoRA switch, not a content label. Set parameters.nsfw=true only if exposed and the user explicitly requests enabling the NSFW mode, flag or LoRA for this image or batch, e.g. 'enable NSFW mode' or 'nsfw=true'. Requests for NSFW, nude, erotic or explicit content, including 'make an NSFW image', do not authorize this switch. Never infer activation from prompts, prompt guidance, references or earlier jobs. Without a clear activation request, omit nsfw or set false and proceed with the requested image. It is independent of draft/standard mode. When multiple images are needed, prefer generate_batch: it is the most efficient way to avoid repeated GPU switching and slow LLM reloads. Prepare all items before calling it. Choose a unique job_id before generate or generate_batch. If a call times out, use get_job with that same ID; do not start another generation. Images are local files. Only an active LLM request triggers GPU restoration.
