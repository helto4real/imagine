Generate or upscale images through Imagine API profiles. First call list_profiles, then describe_profile for the chosen profile. Choose qwen for standard generation and editing, quick-draft for Turbo previews, or a specialized profile from the catalog. Read and apply its full prompt_guidance to parameters.prompt. If has_default_prompt is true, omit prompt to use the stored profile prompt unless the user requests an override. Pass only overrides in parameters; nested objects merge recursively and lists replace completely. Select the profile before registering references; IDs belong to that profile and must be supplied in order. For image_upscale, register exactly one image and pass optional max_side and seed. For profiles with random seed defaults, omit seed for a fresh seed per image or provide an integer for a fixed seed. Results contain the resolved seed. The nsfw flag is an opt-in LoRA switch, not a content label. Set parameters.nsfw=true only if nsfw_available is true and the user explicitly requests enabling the NSFW mode, flag or LoRA for this image or batch, e.g. 'enable NSFW mode' or 'nsfw=true'. Requests for NSFW, nude, erotic or explicit content, including 'make an NSFW image', do not authorize this switch. Never infer activation from prompts, prompt guidance, references or earlier jobs. Without a clear activation request, omit nsfw or set false and proceed with the requested image. It is independent of the selected profile and draft/standard quality. When multiple images are needed, prefer generate_batch: it is the most efficient way to avoid repeated GPU switching and slow LLM reloads. Prepare all items before calling it. Choose a unique job_id before generate or generate_batch. If a call times out, use get_job with that same ID; do not start another generation. Images are local files. Only an active LLM request triggers GPU restoration.
