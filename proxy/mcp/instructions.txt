Imagine makes images and videos. Before anything else, call imagine_guide and follow it: it holds the complete rules, which do not fit here.

Every task works in one workspace. Start with workspace_create and save the returned workspace_key at once where you keep notes for the task, or call workspace_open with a saved key; pass the key to every workspace, image and video tool. If it is lost, ask the user. Imagine never shows host paths; files are named by file_id.

Never set the image nsfw switch unless the user explicitly asks to enable the NSFW mode, flag or LoRA; requests for NSFW, nude, erotic or explicit content do not authorize it. After a timeout, reuse the same job_id and never start another generation. Never ask for passwords or YubiKey PINs.
